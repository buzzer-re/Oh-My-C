# v18.22.0

omc now matches [oh-my-pi](https://github.com/can1357/oh-my-pi) v18.22.0. Upstream had 1,929 commits since v18.18.7. About 840 of them don't apply to omc (changelog edits, upstream's CI, the Rust shell, the browser, the new `computer` and disassembler tools, on-device speech), and the rest were ported to C. As before, I checked the result against the real `omp` 18.22.0 running next to omc on the same mock model.

### Install

```sh
curl -fsSL https://raw.githubusercontent.com/buzzer-re/Oh-My-C/main/install.sh | sh
```

To build it on your own machine instead:

```sh
curl -fsSL https://raw.githubusercontent.com/buzzer-re/Oh-My-C/main/install.sh | sh -s -- --build
# or, from a clone: ./install.sh --build
```

| Archive | Runs on |
|---|---|
| `omc-18.22.0-linux-x86_64.tar.gz` | Linux x86_64 with glibc 2.35+ and OpenSSL 3 (Ubuntu 22.04+, Debian 12+, Fedora 36+) |
| `omc-18.22.0-linux-arm64.tar.gz` | Linux arm64, same requirements |
| `omc-18.22.0-macos-arm64.tar.gz` | macOS on Apple silicon |
| `omc-18.22.0.tar.gz` | the source, for anything else |

The macOS binary isn't notarized: if you download it with a browser, run `xattr -d com.apple.quarantine omc` once.

### Thinking levels for models that don't say

A model from `models.yml` or a local server that doesn't declare `reasoning` used to get no thinking levels at all. Now it gets a provisional ladder, and the first request with a thinking level sends a few small probes in parallel to find out which levels the server really accepts. The answer is cached in `thinking-capability.json` in the agent dir, so it only happens once per model.

### grep is quieter

grep shows only the matching lines by default (`grep.contextBefore` and `grep.contextAfter` are 0), keeps 10 matches per file when it searches several files and 50 in a single one, and tells you when binary files also matched instead of dumping them.

### Providers

- Paused providers can be turned back on with `auth.unpausedProviders` (Google Antigravity is paused again)
- Gemini 4 Hydrogen's long answers continue across 65,536-token segments on the Gemini API, Vertex and Cloud Code Assist, and it gets the `xhigh` level
- Bedrock honors a regional base URL and fails a stream that ends early instead of keeping it
- Rate-limit messages say when the quota resets ("Resets in 71h48m47s")
- A 429 with a zero allowance fails at once and names the header instead of retrying
- The Sofya web search engine (`SOFYA_API_KEY`)

### Tools

- `bash.patterns` allow rules can accept leading `NAME=value` assignments, and pattern layers stack: project and `--config` rules go on top of your global ones
- `read` of `skill://`, `memory://`, `agent://` and the other file-backed URLs shows where the file really lives
- todo `done`, `drop` and `rm` take several tasks at once
- GitHub `run_watch` shows the failing job step
- `ssh://` understands the Host aliases in `~/.ssh/config`
- MCP results look like omp's, and a server that dies says which exit code or signal killed it

### TUI and sessions

- Task lists in Markdown render as `[ ]` and `[x]`
- The ask form takes a note per option (`n` or Alt+N)
- The model picker has Tab / Shift+Tab provider scopes and a ←/→ thinking slider
- Plan review shows "Refine plan" only when you wrote feedback, and Save keeps the review open
- `systemPromptTemplates` picks a system prompt template per model
- `--offline` and `--no-judge`
- `task.steps` runs a subagent in steps, with a progress note after each one
- Ctrl+R then Delete removes a prompt from history, and Alt+Up brings queued follow-ups back as `=>`

### Under the hood

This release also had a fuzzing pass. 17 libFuzzer harnesses (`make fuzz`) ran over every parser that reads something omc didn't write: SSE streams, HTTP, JSON, YAML, sessions, the edit formats, the ask form, Markdown, LSP and DAP framing. ASan, UBSan and TSan ran over the whole test suite. When the disk fills up or the session directory turns read-only, omc now does what omp does: it tells you once and rewrites the session file when it can, so nothing goes missing.

### Not in omc

Credential pools, online model discovery, the browser, the `computer` tool, the disassembler, JS eval, on-device speech, collab and spotlight are still not ported, and omc still runs your system's bash instead of omp's Rust shell, on purpose. The full list is in [docs/status.md](https://github.com/buzzer-re/Oh-My-C/blob/main/docs/status.md).
